# Elevvo_Survey-Data-Cleaning-Insights
Data cleaning and insight generation using Kaggle Data Science Survey 2017-2021.

## 📌 Project Overview
This project involves performing an Exploratory Data Analysis (EDA) and data cleaning on real-world survey data from the **Kaggle Data Science Survey (2017-2021)**. The goal is to transform messy survey responses into a clean dataset ready for analysis.

## 🛠 Tools & Libraries
- **Language:** Python (Jupyter Notebook)
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Data Source:** Kaggle Data Science Survey

## 📋 Key Tasks Completed
* **Data Cleaning:** Handled missing values, removed duplicates, and fixed inconsistent formatting.
* **Categorical Handling:** Applied label encoding and mapping to convert text responses into numerical data for analysis.
* **Insight Generation:** Analyzed respondent behavior and preferences to find meaningful patterns.
